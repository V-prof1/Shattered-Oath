# Shattered Oath

Mobile-first pixel-art top-down action RPG built for landscape play.

## Core pillars
- Mastery-based progression instead of traditional character levels
- Skill tree powered by mastery level-ups
- Melee, ranged, magic, shield and parry combat
- Bosses, elites and craftable relics from enemy materials
- Blacksmith crafting with material + gold service costs
- NPC trainers, quests, merchants and a travelling merchant
- Boss training, arena and additional hub modes
- Post-game corruption system with mutated enemies, elites and bosses
- Persistent exploration, titles, achievements and end-game quests

## Target
- Mobile first
- Landscape 16:9
- Web build for quick testing
- Android packaging later from the same codebase

## Tech
- Phaser 3
- JavaScript ES modules
- HTML/CSS
- GitHub Pages for web testing

Development starts with a small vertical slice before expanding content.
